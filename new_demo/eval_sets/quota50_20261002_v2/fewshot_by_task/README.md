# fewshot_by_task：按任务类别的 few-shot（每类三条）

每类统一三条示例，内容各不相同；消息条数随示例走的工具步数变化。

```text
T1.json  单设备：eq 开关 / eq 模式 / le 方向
T2.json  多设备：两条件+keep / 开关+模式 / 混合 eq+le
T3.json  模糊意图：热闷→空调 / 潮→关加湿器 / 刺眼→主灯调暗
T4.json  危险拒绝：数值越界 / 传感器只读 / 冰箱越界
T5.json  查询：房间读数 / 传感器读数 / 设备状态
```

结构：直接给消息数组（role/content），由 runner 插在 system 与包装过的真实任务之间。
真实任务仍用统一的 [TASK] 包装（示例不是真实环境、一次一个 JSON、最多 12 步）。
