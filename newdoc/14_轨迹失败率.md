# newdoc 14　轨迹失败率（只统计 D5 轨迹）

> 数据：`new_demo/runs/quota200_20261004_v2/`（1000 批）与 `quota50_20261002_v2/`（250 批对照）
> 口径：轨迹失败率 = 未进集的轨迹 / 跑过的轨迹。
> 进集条件 = C-1..C-4 全过 且 D6 为对/跳过；只要有一条不满足就算轨迹失败。
> 本文只看轨迹本身（轮数、动作、C 标签、finish），不含蓝图阶段，也不看画像。

## 0 一屏

```text
1000 批总轨迹失败率 21.1%（268/1268）；250 批 17.2%（52/302）
  T2 39.0%、T3 36.7% 是主要来源；T1 1.0%、T4 8.7%、T5 1.5% 很低

失败模式分两条（两批一致）
  T2：10 轮截断、没交 finish —— 107/128 条 finish 为空
  T3：终态没达标 C-2 —— 83/116 条只有 C-2

轨迹形态（1000 批）
  T2 失败平均 9.64 轮（成功 8.96 轮）；失败里 74 条执行了 3 个动作、32 条 4 个
     → 活基本干完，是"收尾没做完"而不是"没干活"
  T3 失败平均 5.69 轮；失败里 31 条 0 个动作、34 条 1 个、37 条 2 个
     → 是"没做对"，方向/房间/设备选错

环境规模（轨迹所处家里有多少台设备）
  失败率单调上升：≤8 台 14.7% → 9–12 台 20.3% → 13–16 台 25.3% → 17+ 台 29.8%
```

## 2 失败模式（1000 批 C 标签组合）

```text
T2 128 条
  C-1+C-4      79      ← 截断 + 没有 finish
  C-1+C-2+C-4  28      ← 截断 + 终态也没达标
  C-2+C-4      18
  C-2           3
  带 C-1 的 107 条全部 truncated（10 轮用满）

T3 116 条
  C-2          83      ← 只有终态错：动作发生了，但目标没达成
  C-2+C-4      28
  C-1+C-2+C-4   3
  C-1+C-4       2

T1  2 条：C-4（finish 缺 outcome）

```

## 3 轮数与收尾（1000 批）

```text
类别   成功平均轮数   失败平均轮数   失败中 finish 为空   失败中截断
T1        5.11          5.00            0/2                0

T3        6.15          5.69            5/116              5
T4        4.03          5.11            0/19               0
T5        3.83          7.67            2/3                2

T2 失败轨迹的执行动作数分布：0 个=2、1 个=7、2 个=12、3 个=74、4 个=32、5 个=1
T3 失败轨迹的执行动作数分布：0 个=31、1 个=34、2 个=37、3 个=14
```

T2 的失败轨迹几乎都跑到了 9–10 轮，且大多执行了 3–4 个动作——任务本身做完了，最后一步 finish 没来得及交。T3 正好相反：平均只走到 5.7 轮、动作数少，失败发生在"选哪台设备/往哪个方向"上。

## 4 环境规模（1000 批，按 home 设备数分桶）

```text
设备数    全部轨迹              T2+T3
≤8       53/361 = 14.7%        47/180 = 26.1%
9–12     67/330 = 20.3%        61/173 = 35.3%
13–16   134/530 = 25.3%       124/269 = 46.1%
17+      14/ 47 = 29.8%        12/ 22 = 54.5%
```

家越大（房间/设备越多），T2 的多设备探索越容易超过 10 轮，T3 的感受越容易落到错误房间，所以失败率单调上升。

## 5 条件级归因（T2/T3 的失败轨迹）

```text
T2：目标设备从未被成功操作 42 条；动作落在目标设备但值/方向不对 13 条
T3：目标设备从未被成功操作 63 条；动作落在目标设备但值/方向不对 51 条

即：T3 一半是"没碰对设备/房间"，另一半是"碰对了但方向/数值错"；
T2 的失败则主要不是条件级问题，而是整体没收尾（见第 3 节）。
```

## 6 结论

```text
1  轨迹失败率 = 两个独立来源
   T2（39%）：多设备 + 10 轮上限 → 截断没收尾
   T3（37%）：模糊意图 → 终态落错房间/方向

2  修复优先级
   T2：轮数预算（10 → 12）或"动作做完就 finish"的收尾约束（107/107 截断）
   T3：房间选择口径 + 方向一致性（83 条只有 C-2）
   大户型：设备数 ≥13 时失败率 25–30%，优先看轮数预算

3  低优先
   T1/T5 已经接近零失败；T4 的 19 条里 15 条是 finish 契约、4 条是 D6 判错，
   属于收尾细节，不是轨迹策略问题
```
