## 关键结论

- 现行提示词把 `eq / ge / le` 统一成「写、说、查同一映射」一说到底，落盘后 pytest 86 绿。
- 250 条评测集（quota50_20261002_v2）五类各 50 条，全部带成功轨迹，用于评测转化。
- 1.5B 上 few-shot 的收益主要来自类别与示例内容对齐，不是示例条数越多越好。
- 三条版相对 11 版的退化集中在 T4（reason_code 抄工具错误码），状态层失败两版同构，详见 09。
