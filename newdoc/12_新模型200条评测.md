# newdoc 12　新模型 200 条评测：Qwen3-1.7B 与 Qwen3.5-2B

> 日期：2026-10-03
> 目的：在同一批 200 条任务、同一 few-shot 装配、同一判定口径下，对比两个新本地模型与现有 Qwen2.5-1.5B 基线。
> 模型：Qwen3-1.7B-Q8_0（ggml-org）、Qwen3.5-2B-Q8_0（unsloth，文本模式，不用 mmproj）
> 服务：llama.cpp build 10991（Vulkan），`-c 32768 --parallel 2`（每 slot 16K）、`-ngl 99`、`--jinja`、`--no-mmproj`、`-rea off`（关思考）
> 评测：`run_local_eval.py --few-shot`（当前 11 版装配）、`--workers 2`、`--max-turns 12`
> 任务：`quota50_20261002_v2` 每类前 40 条，共 200 条（与 newdoc/09 的 200 条完全一致）

## 0 结论

```text
Qwen3.5-2B   112/200   ← 目前最好，超过 Qwen2.5-1.5B 的 90/200
Qwen3-1.7B    63/200   ← 总分低于 1.5B，但 T4 拒绝题反而更好（21 vs 17）
Qwen2.5-1.5B  90/200   ← 旧基线（11 版装配，newdoc/09）

两件事值得注意：
  一、Qwen3.5-2B 的增益集中在 T1（38/40）和 T2（19/40），T4 反而只有 15/40
  二、Qwen3-1.7B 的失败 119/137 都带 C-4（finish 契约），是典型的「协议没学会」
```

```text
  仅 C-2             52
  仅 C-4             25

```

Qwen3-1.7B 的 C-4 占比异常高：137 条失败里 119 条带 C-4，说明它经常「动作做对了但 finish 契约没写对」（outcome 缺失、拒绝理由码不对、summary 塞 JSON 之类）。Qwen3.5-2B 的结构更接近 1.5B 基线，C-2 是主因。

## 3 观察

```text
1. Qwen3.5-2B 是目前这批任务上最强的本地小模型：
   T1 38/40、T5 31/40 接近可用；T2 19/40 相比 1.5B 的 7/40 是大幅改善
   弱点仍在 T3（9/40）和 T4（15/40）——模糊意图与危险拒绝

2. Qwen3-1.7B 总分 63/200 低于 Qwen2.5-1.5B（90/200），
   但 T4 21/40 是三者最高；T5 只有 14/40（查询题大量失败）
   它的主要问题不是不会做事，而是不会按契约收尾（C-4 占 87%）

3. 两个模型都用 -rea off 关掉了思考模式再评，
   实测响应中没有 reasoning_content 字段，协议与 1.5B 评测一致

4. Qwen3.5-2B 是多模态仓库（带 mmproj），本次只跑文本，
   评测服务用 --no-mmproj，不加载视觉投影
```
