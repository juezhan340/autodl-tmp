## 2 D5 的逐轮交互

A 的 system 提示词是 `data_static/D0_templates/A_policy.md`。每轮 context 里有 observation、tools、history、protocol_feedback，A 只回一个工具调用或 finish。首轮 A 拿到的 observation：

```json
{
  "scenario_id": "sc_T2_112",
  "user_request": "我要早睡了，把次卧电视关掉，书房加湿器也关掉，厨房冰箱别动。",
  "tools": ["observe_home", "inspect_room", "inspect_device", "execute_action", "finish"],
  "last_tool_result": null
}
```

以下是 8 轮原文（inspect 结果给全量字段；observation 里每轮重复的 tools 表不重复抄）。

