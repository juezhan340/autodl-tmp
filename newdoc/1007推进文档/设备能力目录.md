# 设备能力目录（现状快照）

> 依据：`new_demo/data_static/D0_devices.jsonl`（21 台，2026-10-12 快照）。
> 用途：TC6/TC7 出题选设备、TC7A 记忆例子选值、后续代码改动对照。
> 计划新增的空气净化器（仅开关）不在本目录；见 05 开头的"设备变更"说明。

## 0 一屏：谁有"准确档位 / 模式"

```text
有离散模式（enum）        主灯 dim|bright
                          空调 off|cool|heat|auto
                          电视 tv|hdmi|av（信号源，不是频道）
                          热水器 eco|hot
                          洗衣机 normal|quick|delicate|rinse
                          洗碗机 normal|eco|intensive
                          烤箱 bake|broil|keep_warm

有精确数值档位（带 step）  台灯 level 0–100（step 1）
                          风扇 level 0–100（step 1）
                          排气扇 level 0–100（step 1）
                          电视音量 level 0–100（step 1）
                          空调温度 target 7–32（step 0.5）
                          热水器温度 target 35–75（step 1）
                          烤箱温度 target 50–250（step 5）
                          冰箱温度 target 2–8（step 0.5）

只有开关                  走廊灯 / 阳台灯 / 厨房灯 / 卫生间灯 / 夜灯 / 开关 / 加湿器
只读传感器（无动作）       温湿度 / 温度 / 湿度
```

## 1 逐台规格（21 台）

### 1.1 灯（7 台）

```text
主灯 cat_ceiling_light  id_token=light        房间 bedroom / living / study
  state  {on, mode}    动作 turn_on / turn_off / set_mode(dim | bright)

台灯 cat_desk_lamp      id_token=lamp         房间 bedroom / study
  state  {on, level}   动作 turn_on / turn_off / set_percentage(0–100, step 1)

普通灯 ×4（走廊 cat_corridor_light / 阳台 cat_balcony_light /
  厨房 cat_kitchen_light / 卫生间 cat_bath_light）  id_token=light
  state  {on}          动作 turn_on / turn_off

夜灯 cat_night_light    id_token=night_light  房间 bedroom / corridor
  state  {on}          动作 turn_on / turn_off
```

### 1.2 温控（4 台）

```text
空调 cat_climate id_token=climate 房间 bedroom / living / study
  state  {on, mode, target}
  set_mode(off | cool | heat | auto)；set_temperature(7.0–32.0, step 0.5)

冰箱 cat_refrigerator id_token=fridge 房间 kitchen
  state  {on, target}
  set_temperature(2.0–8.0, step 0.5)

热水器 cat_water_heater id_token=heater 房间 bath
  state  {on, mode, target}
  set_mode(eco | hot)；set_temperature(35.0–75.0, step 1.0)

烤箱 cat_oven id_token=oven 房间 kitchen
  state  {on, mode, target}
  set_mode(bake | broil | keep_warm)；set_temperature(50.0–250.0, step 5.0)
```

### 1.3 家电（3 台）

```text
电视 cat_tv id_token=tv 房间 living / bedroom
  state  {on, mode, level}
  set_mode(tv | hdmi | av)（信号源）；set_percentage(0–100, step 1)（音量）

洗衣机 cat_washer id_token=washer 房间 bath / balcony
  state  {on, mode}
  set_mode(normal | quick | delicate | rinse)

洗碗机 cat_dishwasher id_token=dishwasher 房间 kitchen
  state  {on, mode}
  set_mode(normal | eco | intensive)
```

### 1.4 风类与纯开关（4 台）

```text
风扇 cat_fan id_token=fan 房间 bedroom / living / study
  state  {on, level}    set_percentage(0–100, step 1)

排气扇 cat_exhaust id_token=exhaust 房间 bath / kitchen
  state  {on, level}    set_percentage(0–100, step 1)

开关 cat_wall_switch  id_token=switch  房间 living / corridor / kitchen
  state  {on}           turn_on / turn_off

加湿器 cat_humidifier id_token=humidifier 房间 bedroom / living / study
  state  {on}           turn_on / turn_off
```

### 1.5 传感器（3 台，只读）

```text

  state {temperature, humidity}   无动作（写入会被 B 拒绝）

湿度传感器 cat_humidity_sensor id_token=humidity  房间 bath / kitchen
  state {humidity}                无动作
```

## 2 TC7A 记忆选值参考（按"能不能钉死终态"排序）

```text
推荐度   设备 / 字段              记忆里的例子                备注
高        空调 target（7–32, 0.5） "睡觉固定 25.5 度"          首选；别用 26 这类默认值
高        台灯 level（0–100）     "看书要 80%"                数值直观、易判定
高        热水器 mode + target    "洗澡 45 度、hot"           双条件，组合好
高        电视 mode + level       "睡前 hdmi、音量 30"        没有频道；用信号源+音量替代
高        洗衣机 mode             "衬衫用 delicate"           枚举型；不读记忆难猜
高        洗碗机 mode             "碗少用 eco"                同上
中        冰箱 target（2–8, 0.5） "冷藏 4.0 度"               可以
中        主灯 mode               "晚上用 dim"                只有两档
中        风扇 / 排气扇 level     "怕风：别开风扇"（禁做）    数值或禁做都可以
弱        开关型设备              夜灯 / 加湿器 / 走廊灯…     只能表达开/关偏好，容易被猜中
```

## 3 写题注意

```text
1  空调 mode 枚举里有 "off"，与 state.on 并存——写条件时二选一（示例统一用 on）
2  主灯没有 level（只有 dim/bright）；台灯没有 mode；两类灯不要混写
3  电视没有频道字段；要"调台"得先扩字段（同净化器，属设备扩展）
4  空气净化器（air_purifier，仅开关）是计划新增；落地后补进本目录
5  本目录与 D0_devices.jsonl 一一对应；改设备目录时同步改这里
6  暂缓（2026-10-12）：风扇改"低/中/高"离散档、排气扇去档位——讨论后暂不调整；
   若日后要改，卡点是 B_schema.py 的 ALLOWED/REQUIRED_STATE_FIELDS["fan"]
   （方案 A：allowed 加 "mode"、required 只留 "on"，老数据含 level 仍可重放）
```
