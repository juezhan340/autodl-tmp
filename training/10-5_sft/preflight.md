# preflight.py 中文说明

```text
职责：建立准备到运行、观察、核对的最小验证闭环。
输入：config、可选--gpu-smoke、报告目录。
输出：preflight_report.json及同名中文md。
读取：数据manifest、训练教师样例、实际检查点和adapter张量。
写入：数据产物、独立微型冒烟目录、小型报告。
不负责：完整500条训练、200条最终测试、D6外部请求。
```

```text
准备/核对四个集合与全部助手mask
  -> 每类一条训练教师轨迹重放，核对C/B
  -> 可选GPU冒烟：两次更新、每epoch保存
  -> 逐张量重载两个epoch和selected adapter
  -> 训练集合五条真实学生环境交互，D6关闭
  -> 复核基础权重SHA-256未改动
  -> 输出结果
```

教师重放仅证明示范与环境契约一致。五条学生交互仅测试接口，不能用来证明SFT效果。`--gpu-smoke`未指定时不加载模型或更新参数；任何数据、检查点或生成接口检查失败都抛错。

每个epoch单独从基础模型重载，和正式评测保持同一加载路径。PEFT追加多个adapter的路径可能先把FP32权重转换成BF16，预测试不采用这一条路径，也不放宽零误差要求。

`--reuse-smoke`可继续核对已有的两次更新冒烟，避免修复检查步骤后重复更新参数。只接受output_root下的smoke目录，且配置及数据指纹一致、summary显示恰好两次更新。再次做接口检查使用新的评测子目录，不覆盖之前的轨迹证据。
