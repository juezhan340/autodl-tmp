2. 芯片 IP / 架构授权

手机 SoC 大多围绕 Arm 架构生态展开。Apple、高通、联发科、三星等虽然会做大量自研设计，但底层 CPU 指令集和一部分接口 IP，长期离不开 Arm 生态。

3. 手机 SoC 设计公司

4. 晶圆代工制造
节点代表厂商先进晶圆制造TSMC、Samsung Foundry、Intel Foundry
手机旗舰 SoC 最核心的制造节点，目前主要集中在 TSMC。Samsung Foundry 也服务过 Exynos、高通部分芯片，Intel Foundry 则更多处在追赶和争取外部客户阶段。

最先进制程的关键是 ASML EUV。ASML 是 EUV 光刻设备核心供应商，Nikon 和 Canon 主要在 DUV、成熟制程、特定细分市场有存在感。

6. 其他关键晶圆制造设备
节点代表厂商刻蚀 / 薄膜 / 沉积 / 检测Applied Materials、Lam Research、Tokyo Electron
一颗芯片不是靠光刻机单独做出来的。刻蚀、沉积、清洗、离子注入、检测量测也很关键。这里美国和日本厂商占据很强位置。

7. 半导体材料
节点代表厂商光刻胶 / 硅片 / 特气材料Shin-Etsu、SUMCO、JSR
材料端日本厂商非常强。硅片、光刻胶、电子气体、湿电子化学品等环节，直接影响良率和先进制程稳定性。

8. 存储芯片
节点代表厂商DRAM / NAND / UFSSamsung、SK hynix、Micron
手机里的“内存”和“硬盘”更准确地说是 LPDDR 内存和 NAND/UFS 闪存。OECD 报告中也把 Samsung、SK hynix、Micron、Kioxia、YMTC 等列为 DRAM/NAND 重要厂商。OECD

手机 SoC 之外，还有大量外围芯片。比如射频前端、电源管理、Wi-Fi/蓝牙、定位、音频等。苹果虽然主芯片自研，但外围芯片仍长期依赖多家供应商。

封测是晶圆制造之后，把裸 die 变成可用芯片的环节。先进封装对 AI 芯片尤其关键，对手机 SoC 也越来越重要。

节点代表厂商手机品牌Apple、Samsung、小米

线二：华为 / 国产自主可控链路
这条线公开信息没有全球主流线那么透明，所以我把它理解为：以华为海思为核心，尽量用国内 EDA、国内晶圆制造、国内设备材料、国内封测、国内零部件，把手机和 AI 芯片继续做出来。

1. 国产 EDA / 设计软件
节点代表厂商国产 EDA华大九天、概伦电子、广立微

2. 芯片设计
节点代表厂商芯片设计海思、华为昇腾、紫光展锐
手机主芯片上，华为核心是海思 Kirin。AI 芯片上，核心是 Ascend 昇腾。紫光展锐不是华为体系内公司，但属于国产手机 SoC 设计的重要代表。

3. 手机 SoC / AI 芯片产品
节点代表芯片终端芯片Kirin 9000S、Kirin 9020、Ascend 910C

4. 晶圆制造
节点代表厂商国内晶圆制造中芯国际、华虹半导体、晶合集成
先进逻辑芯片上，中芯国际是核心。华虹更强在成熟制程、功率器件、嵌入式存储等方向。晶合集成也属于国内晶圆制造力量之一，但和华为先进 SoC 的直接关系公开信息有限。

5. 国产光刻 / 曝光设备
节点代表厂商国产光刻相关上海微电子、芯碁微装、华卓精科
这一环节是国产线最大短板之一。公开信息通常认为，中国尚未具备可量产先进 EUV 光刻机的能力；因此 7nm 级芯片更多依赖 DUV 多重曝光、工艺优化和高成本制造。Reuters 报道也提到，缺乏先进光刻设备限制了中芯国际先进 AI 芯片的良率。Reuters

6. 国产晶圆制造设备
节点代表厂商刻蚀 / 薄膜 / 清洗 / 热处理北方华创、中微公司、盛美上海
如果说光刻是最难的一关，那么刻蚀、薄膜沉积、清洗、热处理等设备就是国产替代推进最快的几个方向。北方华创、中微公司、盛美上海是公开市场中最常被提到的代表。

7. 国产半导体材料
节点代表厂商硅片 / 光刻胶 / 特气材料沪硅产业、南大光电、彤程新材
材料端同样是“多点追赶”。国产硅片、电子特气、光刻胶、湿电子化学品都有进展，但在最先进制程的稳定性、纯度、批量一致性上仍需要时间。

8. 国产存储芯片
节点代表厂商DRAM / NAND长江存储、长鑫存储、兆易创新
手机里对应 LPDDR 内存、UFS/NAND 闪存。长江存储更偏 NAND，长鑫存储更偏 DRAM，兆易创新主要在 NOR Flash、MCU 等方向更强。

9. 国产射频 / 电源 / 连接芯片
节点代表厂商射频、电源、连接芯片卓胜微、唯捷创芯、圣邦股份
这一层很重要，因为手机不只有 SoC。射频前端、电源管理、模拟芯片、Wi-Fi/蓝牙、卫星通信相关芯片都会影响整机体验。国产替代在这一层推进较快，但高端射频前端仍是难点。

10. 国产封装测试
节点代表厂商封测 / 先进封装长电科技、通富微电、华天科技
国内封测体系相对完整。手机芯片、存储芯片、AI 芯片都需要封装测试。AI 芯片对先进封装要求更高，这一层未来会越来越关键。

11. 手机零部件 / 模组
节点代表厂商屏幕 / 摄像头 / 结构件京东方、舜宇光学、比亚迪电子
华为手机的国产化不仅是芯片，还包括屏幕、摄像头模组、结构件、电池、声学、马达、连接器等一整套供应链。这里每个小类都可以展开，但按你的要求每个节点只放 2–3 家。

12. 终端品牌 / 终端产品
节点代表产品终端华为 Mate / Pura 手机、华为 MatePad、华为 Atlas / 昇腾服务器
