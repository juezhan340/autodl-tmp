## observe_home 会不会返回工具参数？

不会。

```text
observe_home 的 data
  {"rooms": [{"room_id": "...", "display_name": "..."}, ...]}
  没有设备，没有温湿度，没有 actions，没有工具 schema

工具参数从哪来
  四个家庭工具 + finish 的 schema
    每回合都在 observation.tools 里
    填进提示词「可用工具」
    跟有没有调用 observe_home 无关
  某台设备自己的动作和 min/max/enum
    只有 inspect_device 才给
    inspect_room 只给设备摘要（id、显示名、kind、type、available）
```

发给模型时，「可用工具」是 `json.dumps` 一行。下面各回合把这一段展开成缩进 JSON，内容一字不改。历史、上一轮结果仍按当时发出去的紧凑 JSON。

每一回合都是一次新的 chat completion，`messages` 只有一条 user。A 回复落盘只有工具 JSON。`call_id` 是 C 补的。
