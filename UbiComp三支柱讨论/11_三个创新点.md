# 三个创新点

本文档只写三个创新点本身，以及它们相对已有论文新在哪。证据、实验设计、打包方式留待后续文档展开。

| # | 创新点                                                                                                                         | 相对已有论文，新在哪                                                                                                                                               |
| - | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1 | **把"房间连通"做成可计算的世界约束，并据此设计 benchmark**：设备效果沿连通边传播，连通关系改变时正确动作随之改变         | SimuHome 的房间之间是独立状态容器；SMH-Bench 有环境复杂度分档，但没有拓扑因果；PersonalHomeBench 有记忆与个性化，但没有空间；HomeFlow 有可验证环境，但没有空间维度 |
| 2 | **用环境验证的分层奖励训练空间-时间策略**：把"空间语义的运用"显式做成一个训练目标层，奖励全部来自沙盒状态，不用 LLM 裁判 | HomeFlow 有可验证的 RLVE，但训练目标是设备控制，没有空间推理层；其余三篇 benchmark 都不做训练                                                                      |
| 3 | **同一套 agent-facing 语义在沙盒与 Home Assistant 双后端上成对评测**，量化策略迁移的保持率与适配成本                     | HomeFlow、SMH-Bench 都止步于仿真；Home Assistant MCP 类工作只有接口、没有训练闭环；"最广泛适用性"此前没有量化证据                                                  |
