## 3 你点名的三个问题：具体回答

### 3.1 SFT 现在一般用什么（小模型）

```text
主流答案：PEFT（LoRA / QLoRA），不是全参。
  证据：LoRA 23783 引、QLoRA 5827 引、PEFT 综述 1117 引；
        官方仓库 + PEFT/LLaMA-Factory/unsloth 全部支持，社区复现极多。
  全参什么时候用：数据多（十万条以上）、算力够（多卡）、要冲榜。
  1.5B 场景：LoRA/QLoRA 足够，单卡可跑。
数据侧现在一般怎么做：
  ① 精选 > 海量：LIMA（1475 引）1000 条高质量样本即可对齐；
     小模型领域适配同理——把领域数据洗干净比堆量重要
  ② 合成数据补量：phi-1（671 引）"教科书"路线；Self-Instruct 路线
  ③ 多任务配比：Tülu 3（945 引）的做法——按技能分头调配比、
     做消融、再合并；不要等量硬混
  ④ 训练细节：packing、chat template 对齐、多 epoch（小数据 3–10 轮）、
     及时在 held-out 上评测
```

### 3.2 GRPO 现在一般用什么（小模型）

```text
算法主线：GRPO（DeepSeekMath 9472 引）→ DAPO（2787 引）
         → Dr.GRPO / R1-Zero 分析（1410 引，纠长度与难度偏差）
小模型可行性证据：
  TinyZero（13.3k★）   3B 模型复现 R1-Zero，证明小模型 GRPO 可训
  simpleRL-reason（3.9k★）7B 上系统复现，社区教程多
工具选择：verl（23.7k★，最主流）、TRL GRPOTrainer（19.5k★，轻量）、
         OpenRLHF（10.1k★）
1.5B 实操要点：
  ① group 大小 G 取 4–8（显存换得来）；rollout 用 vLLM 加速
  ② 用 LoRA + GRPO 可把显存压到单卡
  ③ 奖励用规则 verifier（你们的 C 标签自动判定正好合适）
  ④ 开 DAPO 式动态采样（全对/全错组降权），但给每类留保底配额
```

### 3.3 课程 / 动态训练，他们一般用什么

```text
证据最强的不是"花哨调度"，而是朴素的"分阶段换数据"：
  DAPT/TAPT（Don't Stop Pretraining 3237 引）就是最早的"课程"：
  先在领域数据上继续预训练（DAPT），再在任务数据上微调（TAPT）。
  2024–2025 的主流报告（OLMo 2、Tülu 3、MiniCPM）都是分阶段配方。
有实现可抄的课程学习：DeepSpeed Data Efficiency（先算样本难度，
  再按调度先易后难）——工具级可复现。
动态难度（论文级）：AdaRFT（96 引，按奖励信号自动调难度）最能复现；
  更新的 RoD（按遗忘分配回放）、ADS、MoDoMoDo 引用都很低（个位数到几十），
  属于"可以做、可以写，但要自己补验证"的增量研究。
结论：课程/动态调度适合作为你们论文里的"小模块"，
      底座引 Bengio（7736 引）+ 分阶段做法，增量对比引 AdaRFT/RoD。
```

      底座引 Bengio（7736 引）+ 分阶段做法，增量对比引 AdaRFT/RoD。

```

## 6 分档结论：哪些"广泛验证可用"，哪些只是"新"
```text

✅ 广泛验证可用（多篇高引 + 多工具 + 社区复现）
   LoRA / QLoRA / PEFT（微调标准答案）
   DAPT + TAPT（领域适配经典做法）
   LIMA 式数据精选（质量>数量）
   GRPO + DAPO（RL 主线，verl/TRL/OpenRLHF 都实现了）
   TinyLlama / MiniCPM 的小模型训练配方
   DeepSpeed Data Efficiency 的课程学习实现
🟡 可以做的增量（新，引用低，需要自己补实验）
   AdaRFT（96 引，动态难度最可复现）
   RoD / ADS / MoDoMoDo（回放分配、在线调度）
   DISCO（域不平衡 GRPO 奖励缩放）
⚪ 只做背景引用（太老，别当主方法）
   Bengio 课程学习（2009）、Hinton 蒸馏（2015）——
   写法：作为"思想来源/背景"，主方法用近三年的

```
