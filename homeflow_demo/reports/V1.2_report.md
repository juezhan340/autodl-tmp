## 已实现契约

```text
发现链
  observe_home
    -> inspect_room
      -> inspect_device
        -> execute_action

环境边界
  HomeEnv 不读取隐藏 conditions/keep
  HomeEnv 不计算 reward，不处理 finish
  传感器 actions=[]，写入返回 UNSUPPORTED_ACTION
  动作先完整校验再写入，失败无部分状态变化
  snapshot/restore/fork 同时保存运行状态和发现状态

评测边界
  C 统一管理 turn、finish、隐藏 verifier、reward 和错误归因
  策略错误 / 环境故障 / 未决错误分开统计
  成功和失败轨迹都执行确定性重放
  accepted_for_sft 只接收成功、无错误污染、结构完整的轨迹
```
