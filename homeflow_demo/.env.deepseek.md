# `.env.deepseek` 配置说明

## 用途

这个文件只保存 HomeFlow Demo 调用 DeepSeek API 所需的本地配置。DeepSeek 负责生成候选用户表达和工具调用轨迹，HomeEnv 负责执行轨迹并判断成功与否。

## 输入

```text
DEEPSEEK_API_KEY：   你的 DeepSeek API 密钥，必须本地填写
DEEPSEEK_BASE_URL：  API 地址，默认 https://api.deepseek.com
DEEPSEEK_MODEL：     默认 deepseek-flash
DEEPSEEK_TIMEOUT：   单次请求超时秒数
DEEPSEEK_MAX_RETRIES：请求失败后的最大重试次数
DEEPSEEK_TEMPERATURE：候选轨迹生成温度
DEEPSEEK_MAX_TOKENS： 单次响应最大 token 数
```

## 使用方式

```text
1. 打开本文件同目录下的 `.env.deepseek`
2. 只填写 `DEEPSEEK_API_KEY=` 等号后面的密钥
3. 不要把密钥粘贴到 Python 文件、JSONL、日志或 Git 提交中
4. DeepSeek API 调用代码读取 `.env.deepseek`，不要读取聊天记录中的密钥
```

密钥填写位置：

```text
/root/autodl-tmp/homeflow_demo/.env.deepseek
```

## 输出

这个配置文件本身不产生训练数据。API 调用模块应把原始响应写入：

```text
homeflow_demo/data_raw/deepseek/
```

后续由 HomeEnv 验证器判断轨迹是否成功，不能直接把 DeepSeek 原始响应当作 SFT 数据。

## 安全约束

```text
DEEPSEEK_API_KEY 不能为空，否则调用前应直接报错
日志只记录 request_id、模型名和错误类型，不打印完整请求头
原始响应可以保存，但不得包含 API key
`.env.deepseek` 已加入 homeflow_demo/.gitignore
```
