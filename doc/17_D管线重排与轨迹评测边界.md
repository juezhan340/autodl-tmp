# D 管线重排与轨迹评测边界

> 日期：2026-09-26
> 性质：目标规格，不改当前代码
> 依据：HomeFlow 原文的 HomeMaker、Blueprint、线性轨迹；SMH-Bench 的环境先行、任务模板和回放取真值
> 排除：MCTS-Flow

当前代码仍是 V1.2 写死户型与中文任务，外加 V2 用 `writer_view` 中文让模型改写。本文记录要改成的 D，以及它和 A、B、C 的边界。

```text
D0 静态库
  人工维护的户型与设备目录、按任务族 T 存放的提示词模板
  模板只约束任务族和说法，不保存「把卧室主灯关掉」这种现成请求
  落到数据文件，不写在 _build_home 或 _build_blueprint 的中文句子里
  不实例化 s0，不写用户指令，不生成 Phi
        |
        v
D1 HomeMaker
  程序从 D0 采样并实例化 s0，不调用模型
  输出可被 B reset 的 home：房间、设备、display_name、actions、当前 state
  先从静态目录抽样并改变初始状态
  不能把五间房七台设备写死在 Python 分支里
        |
        v
D2 第一次外部模型，不是 A
  读序列化后的 s0 和该任务族模板
  写出结构化规范：要变什么、要保持什么、问什么、拒绝什么
        |
        v
D3.1 程序绑定，只此一次
  显示名和动作槽位绑定到本份 s0 的 device_id
  对照 B 的 DEVICE_TYPES、SUPPORTED_ACTIONS 和参数范围
  设备不存在、动作不存在、参数越界：保留失败记录，停止
  不再生成用户指令，不进入 D4
  通过后由程序写成隐藏 Phi：conditions、keep、查询目标或拒绝原因
  模型不直接书写最终 Phi
        |
        v
D3.2 外部模型审查规范，不是 A
  规范是否属于该任务族，有没有和模板冲突
  只报告，不改规范
        |
        v
D2 第二次外部模型，不是 A
  只看见已通过的规范，写一条用户指令
  指令中不得出现 device_id、action 名、reason_code
        |
        v
D3.3 指令校验
  程序查 blueprint 实例值和工具 JSON 字段名泄露
  外部模型查指令是否覆盖规范、有没有额外设备或动作
        |
        v
蓝图 = <s0, 用户指令, 隐藏 Phi>
  三步都过才算任务合理
  失败蓝图留记录，不进入 D4
        |
        v
D4 线性轨迹
  跑通 B/C：A = OraclePolicy，只验收环境和回合，不作为 SFT 主数据
  准备 SFT：A = 外部助手模型，每轮只看 C 给的 context，看不到 Phi
  C 驱动 A.respond 与 B，一条轨迹，不超过 max_turns
  不做 MCTS，失败不分叉重采样
        |
        v
C 轨迹评测
  用 Phi、B 的运行时状态和工具事件判断助手是否做对
  输出 success、reward、是否可进入 SFT
  不判断模板是否合理，不改用户指令，不造 s0
  蓝图合法而轨迹失败，是助手没做对，不是任务不合法
  成功轨迹留给 SFT

A 只决定下一步工具调用
  不写户型，不写规范，不写用户指令，不审查蓝图
  当前：oracle_policy.py、deepseek_policy.py
  V1.2 由 planner.py 把 Oracle 交给 C
  V2 rollout 由 build_v2_dataset.py 把 DeepSeekPolicy 交给 C

B 执行沙箱
  reset 进来的运行时状态，执行四个家庭工具
  不保存户型库，不读 Phi，不处理 finish
  当前：home_env.py、state_engine.py
  设备种类和动作闭集在 env/schema.py
  具体户型仍在 data/scenario_generator.py，不在 B 里

工具 schema 由 B 和 C 共用，不拆成两份
  定义：env/tool_schema.py 的 available_tools()
  C 每轮放进发给 A 的 context，include_finish=True，finish 自己处理
  B 的 observation 带同一份说明，include_finish=False，只执行家庭工具

尚未实现
  D0 数据文件、D1 从目录采样、D2 先规范后指令
  D3 绑定一次再审规范再审指令、D4 只消费完整蓝图
  失败蓝图的独立记录
  V2 现有 writer_view 中文改写不是这条管线的目标
```
